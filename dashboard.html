ENGINEERING NOTES — BUGS FOUND DURING VALIDATION
01 · "NULL ISLAND" GEOLOCATION BUG
Impossible-travel detection initially returned 0% recall despite real country changes being present. Root cause: unmapped country codes silently defaulted to (0, 0) — a real coordinate off the Gulf of Guinea. Two different unmapped countries would collapse onto the same point, making genuine travel invisible. Fix: unmapped countries now return None and are explicitly skipped rather than guessed, with the missing codes logged for review.
02 · SPARSE LOGIN HISTORY MASKING ATTACKS
Even after the geolocation fix, several real country-change attacks still went undetected. Root cause: accounts login only ~10 times over 30 days, so an injected attack's nearest chronological neighbor could be days away — collapsing the required travel speed below the detection threshold regardless of actual distance. Fix: each injected attack now includes a realistic "last known normal login" 20–90 minutes prior, mirroring how real impossible-travel detection always compares against the victim's most recent session.
